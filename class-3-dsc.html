GOOD TO KNOW

How a Class 3 DSC works for bidders and businesses

A Class 3 Digital Signature Certificate is the certificate most government e-procurement portals ask bidders to use. It proves the identity of the person signing and is stored on a secure USB token, so a bid or filing can be signed online and checked later.

Which certificate you need depends on the portal. Many e-tender portals ask for both signing and encryption, while some filings only need signing. We confirm the portal requirement with you before you pay, so you do not end up with the wrong certificate.

FAQ

Frequently asked questions

What is the difference between signing and signing + encryption certificates?+

A signing certificate lets you digitally sign documents and forms. A combo certificate adds an encryption certificate, which many e-tendering portals use to protect price bids. Check the tender portal instructions or ask us before applying.

Do I need a USB token for a Class 3 DSC?+

Class 3 certificates are normally issued on a secure USB token that holds your private key. You plug it into the computer you use for signing and install the token driver.

How long does it take to get a Class 3 DSC?+

The timeline depends on the Certifying Authority and on how quickly your documents and video verification are completed. We guide you through each step so there are no avoidable delays.

Can one DSC be used for GeM, e-tendering, MCA, GST and Income Tax?+

A compatible Class 3 certificate can be used on many of these portals, but each portal has its own requirement. We help you check compatibility before you buy.
